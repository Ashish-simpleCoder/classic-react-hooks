## Read the Documentation

https://classic-react-hooks.vercel.app/

## ✨ Features

-  Comes with treeshaking
-  Typescript support
-  Small bundle size
-  Minimal and Easy to use

## 🛠️ Tech Stack
- React 18 with TypeScript
- Vitepress for documentation
- Changeset for sementic version releases
- Vitest for testing the components
- tsup for build tooling 


## ⚛️ Hook APIs

-  use-event-listener
-  use-copy-to-clipboard
-  use-local-storage
-  use-outside-click
-  use-debounced-fn
-  use-throttled-hook
-  use-is-online
-  use-timeout-effect
-  use-interval-effect
-  use-synced-ref
-  use-synced-effect
-  use-on-mount-effect
-  use-counter


## 🚀 Install in your project

For npm users

```bash
$ npm install classic-react-hooks
```

For pnpm users

```bash
$ pnpm install classic-react-hooks
```

For yarn users

```bash
$ yarn add classic-react-hooks
```

For bun users

```bash
$ bun add classic-react-hooks
```
